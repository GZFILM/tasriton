# תסריטון

כותבים סצנה, שורה אחרי שורה. אפליקציית תסריט לכיתות ג׳–ו׳.

**האפליקציה:** https://gzfilm.github.io/tasriton

- בוחרים סיפור, מקום ודמויות, ובונים תסריט שורה אחרי שורה.
- קבוצות: כל קבוצה שומרת את העבודה שלה בטאבלט וממשיכה בשבוע הבא.
- אודישנים (מוגבלים) ואחריהם "אקשן!": צילום הסצנה.
- מצב מורה עם קוד: כתיבת סיפורים ושליחתם לתלמידים בקישור.

**פרטיות:** הכל נשמר רק במכשיר עצמו. סרטונים, תסריטים ושמות לא נשלחים לשום מקום.
האפליקציה עובדת גם בלי אינטרנט אחרי הפתיחה הראשונה.
